# Falcon Trans — сайт для GitHub Pages

Федеральная транспортная компания. Ультрасовременный одностраничник.

## 🚀 Запуск на GitHub Pages

1. Закоммитьте файлы в ветку `main` (уже сделано локально — сделайте `git push`).
2. На GitHub: **Settings → Pages → Deploy from a branch → main / root**.
3. Сайт будет доступен: `https://superpirov.github.io/falcontrans/`

Файл `.nojekyll` уже добавлен, чтобы Pages отдавал всё как есть.

## 📁 Структура

- `index.html` — весь контент + SEO
- `styles.css` — дизайн, анимации, параллакс-трассы
- `script.js` — скролл-движок, калькулятор, трекинг, слайдер
- `404.html` — кастомная 404 для Pages
- `.nojekyll` — отключение Jekyll

## ✨ Фишки

- Прелоадер с фурой, кастомный курсор, прогресс скролла
- Hero с LIVE GPS-картой, движущиеся фуры/газели/погрузчики при скролле
- Sticky-сцена «Караван едет через Россию» — 4 машины с разной скоростью
- Интерактивный погрузчик: вилы поднимаются от скролла
- Калькулятор с реальными ставками 2026, трекинг-модалка, отзывы-слайдер
- Полная адаптивность, GSAP ScrollTrigger, tilt-эффекты

## 🔧 Локальный просмотр

```powershell
cd falcontrans
python -m http.server 8000
# открыть http://localhost:8000
```

## 🏠 Переезд на свой хостинг

Просто скопируйте 3 файла на любой хостинг (nginx/apache/timeweb). Никакой сборки не нужно. Для своего домена добавьте файл `CNAME` с доменом.

Контакты-заглушки: `8 800 555-35-35`, `zakaz@falcontrans.ru` — замените на реальные.
